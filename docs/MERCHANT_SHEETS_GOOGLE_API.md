# Google Sheets → Merchant Center ([GGL])

OAuth как в [`alumineu-finance-ops`](https://github.com/krvzdrv/alumineu-finance-ops): `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `token.json`, scope **`https://www.googleapis.com/auth/spreadsheets`**.

## Официальный шаблон Google (RU)

В репозитории сохранена копия файла из Merchant Center:

`feeds/templates/google_merchant_products_source_ru.xlsx`

Структура листа:

| Строка | Содержимое |
|--------|------------|
| 1 | Заголовки атрибутов (`id`, `title`, …) |
| 2 | Подсказки по столбцам (из снимка при `--apply`, если не `MERCHANT_RESTORE_HINT_ROWS=0`) |
| **3+** | **Каталог** — после первого `--apply` официальные строки 3–5 шаблона **удаляются из листа** (`DeleteDimension`), товары начинаются сразу под строкой 2 (обычно строка **3**). Режим учебных примеров: `MERCHANT_KEEP_GOOGLE_EXAMPLES=1` — блок 3–5 не удаляется, данные по-прежнему со строки **6**. |

Если первая строка как у шаблона Merchant, скрипт **смотрит содержимое листа**: «классический» шаблон (примеры / пустые 3–5 и каталог с **6**) → перед записью **удаляет три строки** 3–5; если каталог уже начинается с **3**, повторный запуск **не удаляет** строки с товарами. Явный `MERCHANT_DATA_START_ROW=6` в `.env` после перехода на компактный лист переопределяется автоматически на **3** (в лог пишется предупреждение) — либо задайте `MERCHANT_DATA_START_ROW=3`, либо уберите переменную.

При `--apply` без `MERCHANT_KEEP_GOOGLE_EXAMPLES=1` восстанавливается **только строка 2** из `feeds/templates/merchant_products_source_rows_2_5.json`, затем удаляются строки шаблона **3–5**. Полный блок 2–5 из снимка с примерами — только при `MERCHANT_KEEP_GOOGLE_EXAMPLES=1`.

Явный `MERCHANT_DATA_START_ROW` в `.env` имеет приоритет, кроме случая «в .env 6, на листе уже компактная вёрстка». Для листа «только заголовок и товары» без строки подсказок используйте `MERCHANT_DATA_START_ROW=2`.

Скрипт **очищает и перезаписывает** строки начиная с первой строки данных вниз (до 20000).

### Важно для загрузки именно в Merchant Center

В самом шаблоне Google предлагают убрать строки 2–5 — чтобы **фид не воспринимал подсказки и примеры как товары**.

Типичное поведение источника «Google Таблицы» в Merchant Center: **строка 1 = заголовки, каждая следующая строка = оффер**. После синка примеры и строка «Удалите…» **отсутствуют как строки**; под строкой заголовков остаются заголовочная строка шаблона в строке 2 и сразу офферы. **Строка 2** (подсказки) может мешать парсингу — см. варианты ниже.

Практические варианты:

1. **Рабочий лист для MC без строк 2–5** (дубликат листа только с заголовком и данными), а полный шаблон держать для людей.
2. Перед подключением листа к MC **удалить строки 2–5**, как просит Google (после синка можно восстановить из `feeds/templates/…xlsx`).
3. Уточнить в интерфейсе MC для вашего типа источника, есть ли **диапазон строк** (если появится — задавать с строки данных).

## Обязательные поля (базовый чеклист для Shopping)

Скрипт выводит предупреждения/ошибки в консоль; при `MERCHANT_STRICT_VALIDATION=1` ошибки блокируют `--apply`.

Для большинства офферов должны быть заполнены:

- **id** — уникальный идентификатор строки фида  
- **title** — до ~150 символов (в подсказке шаблона — 150; спецификация Merchant допускает до 150 для поверхности объявления)  
- **description** — в шаблоне в подсказке указано короткое описание; актуальный верхний предел для Merchant см. [спецификацию атрибутов](https://support.google.com/merchants/answer/7052112)  
- **availability** — `in_stock` | `out_of_stock` | `preorder` | `backorder` (Meta `in stock` конвертируется в `in_stock`)  
- **link** — страница товара, обычно `https://…`  
- **image link** — прямой URL картинки (JPEG/PNG/WebP и т.д.)  
- **price** — формат вроде `12.00 PLN` (число + пробел + ISO 4217)  
- **identifier exists** — `yes` или `no`  
- **brand** — часто обязателен для EU / Shopping  
- **condition** — `new` / `refurbished` / `used`

Если **identifier exists** = `yes`, обычно нужны **gtin** и/или связка **brand + mpn** (правила зависят от категории и страны).

Для **preorder** / **backorder** обычно нужна **availability date**.

Доставка (**shipping**) в этом шаблоне отсутствует — задаётся в настройках Merchant Center или отдельными атрибутами.

## Переменные `.env`

- `GOOGLE_MERCHANT_SPREADSHEET_ID` — таблица «Alumineu Merchant — PL» и т.п.  
- `MERCHANT_OUTPUT_SHEET_NAME` — например `Products source`  
- `META_CSV_PATH` — экспорт Meta  
- `MERCHANT_TILDA_CSV_PATH` — экспорт Tilda Store (колонки `External ID`, `Photo`, `Url`) для **static.tildacdn.com** вместо Drive  
- `MERCHANT_DATA_START_ROW` — опционально; если не задано, авто по строке «Удалите строки 2–5»  
- `MERCHANT_STRICT_VALIDATION=1` — не делать `--apply` при ошибках валидации  

## Команды

```bash
npm install
npm run merchant:sheet
npm run merchant:sheet:apply
```

## Известные риски данных

- URL вида **`drive.google.com/uc?id=…`** часто **не проходят** проверку изображений в Merchant — задайте **`MERCHANT_TILDA_CSV_PATH`** (экспорт Tilda Store) или прямые CDN/сайт URL.  
- Для **нескольких стран** нужны отдельные цены/валюта/доставка по правилам каждой программы продаж.
